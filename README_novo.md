# 🎓 AtendeLab

Aplicação web desenvolvida para auxiliar no gerenciamento de atendimentos acadêmicos, criada durante a disciplina de Fábrica de Software.

## 📌 Objetivo
O sistema foi desenvolvido para facilitar o registro, acompanhamento e organização dos atendimentos realizados em ambiente acadêmico.

## 🛠️ Tecnologias
- PHP 8
- MySQL
- HTML5
- CSS3
- Bootstrap
- phpMyAdmin
- Git
- GitHub

## ✨ Recursos
- Página inicial pública
- Login
- Dashboard
- Cadastro de pessoas atendidas
- Cadastro de tipos de atendimento
- Registro de atendimentos
- Relatórios

## 🚀 Como executar
1. Clone o repositório.
2. Coloque a pasta em `htdocs` do XAMPP.
3. Inicie Apache e MySQL.
4. Crie o banco `atendelab`.
5. Importe `database/atendelab.sql`.
6. Acesse `http://localhost/atendelab/public/`.
